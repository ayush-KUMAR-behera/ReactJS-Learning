# Form Handling

Learned how to handle forms and user input in React using controlled components and `useState`.

## Topics Covered

- `onSubmit`
- `onChange`
- `event.preventDefault()`
- Controlled Components
- `useState` with forms
- Form validation
- Clearing input after submission
- Array state
- Conditional rendering
- Dynamic list rendering with `map()`

## Projects

### Demo 1 — Basic Form
Handled form submission and prevented the default page reload.

### Demo 2 — Controlled Input
Connected an input field with React state and reset the input after submission.

### Form Handling UI
Built a small UI that accepts names, stores submissions in an array, validates empty input, and displays submitted names dynamically.

## Key Concept

Input → onChange → State → Submit → Validation → Store → Display
