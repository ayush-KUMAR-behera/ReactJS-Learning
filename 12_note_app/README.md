# Notes App

A simple Notes App built using React and Tailwind CSS.

## Features

- Add notes with a title and details
- Display recent notes
- Delete notes
- Validate empty titles
- Clear inputs after submission
- Display a message when no notes exist

## Concepts Learned

- `useState`
- Controlled inputs
- Form handling with `onSubmit`
- `onChange` events
- `e.preventDefault()`
- Rendering lists using `.map()`
- Deleting items using `.filter()`
- Conditional rendering
- Updating arrays in state

## Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Vite

## Note

Notes are stored in React state and are not persisted after a page refresh.
