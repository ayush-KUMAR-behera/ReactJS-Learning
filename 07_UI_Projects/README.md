## Project

## Concepts Practiced

- Component-based UI
- Props
- Passing data between components
- Array of Objects
- `.map()`
- Reusable Components
- Tailwind CSS
- Flexbox
- Custom layouts
- Horizontal scrolling
- Dynamic card content
- Inline dynamic styles
- Remix Icons
