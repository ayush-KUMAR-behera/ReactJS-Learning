# Day 17 — React Router Project

## Overview
Built a multi-page React application using React Router. Users can navigate between Home, About, and Contact pages while sharing a common Navbar and Footer.

## Features
- Client-side navigation with `Link`.
- Route configuration using `Routes` and `Route`.
- Separate page components.
- Reusable Navbar and Footer components.
- Tailwind CSS styling.

## Concepts Learned
- React DOM basics.
- Client-side routing.
- URL paths and route matching.
- Component-based page organization.
- Shared layouts across multiple pages.

## Routes
- `/` — Home
- `/about` — About
- `/contact` — Contact

## Tech Stack
- React.js
- React Router DOM
- JavaScript
- Tailwind CSS
- Vite
