## Key Concepts

- `axios.get(url)` sends a GET request.
- `await` waits for the Promise to settle.
- `response.data` contains the response body.
- `setData()` updates state and triggers a re-render.
- `.map()` renders the fetched array.

## Data Flow

Button Click → Axios Request → API Response → React State → UI
